# MatchPro

Site de mise en relation pour le nettoyage en Suisse romande (fin de bail, fin de chantier, bureaux).

- `site/` : les pages publiées (seul dossier mis en ligne, voir `netlify.toml`).
- `site/assets/matchpro.js` : réglages (`CONFIG` en haut du fichier) et formulaire.
- Domaine : `https://matchpro.ch` est écrit dans les balises, `sitemap.xml` et `robots.txt` ;
  s'il change, rechercher-remplacer `https://matchpro.ch` dans tout le dossier `site/`.
